# Methodology

How the phase-2 research synthesis (`docs/research/`) maps to the engine's
implementation choices. This document is the bridge between "what the literature
says" and "what the code does": each pillar links the research note that
motivated it, the ADR that locked the decision, the module that implements it,
and the M5 figure (or report section) that illustrates it. It is a
cross-reference index, not a re-derivation; follow the links for the full
treatment.

The worked example that exercises every pillar is the JT1993 12-1 momentum study
(`examples/sp500_momentum_study.py`); its figures are regenerated by
`make figures` (or `python scripts/figures/regenerate.py`) from a committed
artifact, in seconds, without the (gitignored) Sharadar bundle.

## Pillars

### 1. Point-in-time discipline

The cardinal sin of equity backtesting is leaking future information. Two leaks
dominate: using a back-adjusted close (which bakes every future split and
dividend into today's price) and using today's index membership for a historical
window (survivorship). The engine reconstructs total return FORWARD from raw
`closeunadj` plus explicit point-in-time corporate actions, never the
back-adjusted `close`, and resolves S&P 500 membership from as-of quarterly
snapshots.

- **Research**: [`methodology-point-in-time.md`](research/sources/methodology-point-in-time.md), [`total_return_reconstruction.md`](methodology/total_return_reconstruction.md)
- **Decision**: ADR [0017](decisions/0017-sp500-snapshot-universe-model.md) (snapshot universe); the total-return reconstruction methodology doc
- **Implementation**: `data/adjustments.py::reconstruct_total_return` + `to_as_traded_dividends` (the dividend basis decode, ADR 0018); `data/universe.py::SharadarSP500Universe.members_at` (as-of); `signal/momentum.py` (forward TR reconstruction with in-window split co-adjustment and as-traded dividends, never the back-adjusted close)
- **Figure**: none of its own (PIT discipline underlies every figure); the worked study at [`docs/figures/momentum_equity.png`](figures/momentum_equity.png) is run entirely on PIT data, and the survivorship quantification is Pillar 5 (its figure is deferred, see below)

### 2. Cost realism

Transaction costs are modeled with the Almgren 2005 square-root market-impact law
(`eta=0.142, beta=0.6, gamma=0.314`) plus an explicit per-share commission. The
M5 study reports a cost-sensitivity band by sweeping `eta`, but it is labelled a
**uniform-liquidity eta-sensitivity surface, NOT a realized-cost estimate**: a
single SPY-typical market-state row is applied to all ~930 names, so per-name
volatility / ADV / shares-outstanding (an M3+/out-of-scope refinement) is not
captured. At that uniform liquidity the impact on the strategy's small per-name
trades is sub-bp, so the band is reported as a table (not plotted), and the
headline Deflated Sharpe stays zero-cost (no after-cost-deflated claim). The
contiguous-vs-CPCV commission seam is decomposed in the report's "CPCV seam cost"
section.

- **Research**: [`methodology-almgren-chriss.md`](research/sources/methodology-almgren-chriss.md)
- **Decision**: ADRs [0005](decisions/0005-m2-cost-realism-plan.md) / [0006](decisions/0006-trailing-period-spy-reconciliation.md) / [0007](decisions/0007-fim-2018-demoted-to-upper-ceiling.md) (cost model), [0010](decisions/0010-sensitivity-band-runner.md) (sensitivity band), [0016](decisions/0016-cpcv-deterministic-factor-and-block-bootstrap-uncertainty.md) PR 3c amendment (the seam decomposition + the uniform-liquidity caveat)
- **Implementation**: `execution/cost/impact.py::SquareRootImpactCostModel`; `execution/matching.py::SquareRootImpactMatchingEngine`; `analytics/sensitivity.py::SensitivityBand`
- **Figure**: reported as a table (the study report's "Cost sensitivity" + "CPCV seam cost" sections), not a PNG, because the eta sensitivity is sub-bp at SPY-uniform liquidity

### 3. Validation: CPCV degeneracy and the block-bootstrap path surface

Combinatorial Purged Cross-Validation (Lopez de Prado 2018, AFML ch. 12) is the
primary validation tool, but its `phi(N,k)` path dispersion comes from
model-fit variance. A deterministic single factor like momentum has no fitted
parameter, so its CPCV paths COINCIDE: the study runs CPCV and reports that
degeneracy honestly rather than dressing a single line up as a distribution. The
genuine path-uncertainty surface is a Politis-Romano stationary block bootstrap
of the monthly return series, with the block length set by the Politis-White
(2004) automatic data-driven selector. On the real series PW judges the monthly
returns near-iid (b_opt 0.46), correctly overriding the isolated lag the naive
ACF rule would treat as significant; the study reports that raw value and applies
a conservative minimal block floor.

- **Research**: [`methodology-afml-backtesting.md`](research/sources/methodology-afml-backtesting.md), [`methodology-backtest-overfitting.md`](research/sources/methodology-backtest-overfitting.md)
- **Decision**: ADR [0001](decisions/0001-spec-critique.md) (CPCV primary), ADR [0016](decisions/0016-cpcv-deterministic-factor-and-block-bootstrap-uncertainty.md) (the degeneracy finding + the block bootstrap as the headline path surface)
- **Implementation**: `validation/cv.py::CPCVSplitter`; `engine/runner.py::Runner.run_cpcv`; `analytics/bootstrap.py::stationary_block_bootstrap` + `politis_white_block_length` (the automatic block-length selector)
- **Figure**: [`docs/figures/bootstrap_fan.png`](figures/bootstrap_fan.png) (the equity projection of the bootstrap; the report quotes its Sharpe projection)

### 4. Deflated performance (PSR / DSR / MinTRL)

A single observed Sharpe overstates skill when many strategies were tried. The
engine reproduces the Bailey-Lopez de Prado 2014 Probabilistic and Deflated
Sharpe Ratios and the Minimum Track Record Length. The M5 study is ONE
pre-specified strategy with no multiple-testing family, so the trial registry is
queried at `naive_effective_n=1` and the DSR degenerates to the PSR against a
zero benchmark, the honest single-strategy reading. The HHI on the monthly PnL
contributions (temporal concentration) is reported alongside.

- **Research**: [`methodology-backtest-overfitting.md`](research/sources/methodology-backtest-overfitting.md)
- **Decision**: ADR [0013](decisions/0013-psr-dsr-mintrl-public-api-and-bailey-ldp-2014-pin-correction.md)
- **Implementation**: `analytics/sharpe.py::psr/dsr/min_trl`; `validation/trial_registry.py::TrialRegistry`; `analytics/concentration.py::hhi`; `analytics/result_adapter.py`
- **Figure**: [`docs/figures/momentum_equity.png`](figures/momentum_equity.png) (annotated with the per-period Sharpe / PSR / DSR) and [`docs/figures/by_year.png`](figures/by_year.png)

### 5. Survivorship and spin-off bias

Using the current index roster for a historical window excludes the names that
delisted, inflating returns. The engine's PIT universe avoids this; the
survivorship study quantifies the bias as the equal-weight CAGR delta between the
PIT-2010 cohort and the current cohort. The v1 worked studies do not consume the
engine's spin-off cash-equivalent path at all: the momentum signal, the dividend
cash-crediting, and the survivorship buy-and-hold all read only `dividend` and
split-like actions, so a spin-off is dropped entirely and the parent's ex-date
price drop is read as a loss, a strictly larger negative bias than the
cash-equivalent treatment ADR 0002 decision 14 anticipated. The literature, the
verified treatment, and an honest real-data quantification (per-name large, e.g.
GE understated about 40 percent; aggregate small, the survivorship delta would
shrink about 9 bps) are in
[`0003-spinoff-bias.md`](research/0003-spinoff-bias.md).

- **Research**: [`methodology-point-in-time.md`](research/sources/methodology-point-in-time.md), [`0003-spinoff-bias.md`](research/0003-spinoff-bias.md)
- **Decision**: ADR [0017](decisions/0017-sp500-snapshot-universe-model.md); ADR [0018](decisions/0018-as-traded-dividend-basis.md) (as-traded dividend basis); ADR [0002](decisions/0002-roadmap-review.md) decision 14 (spin-off bias, citing Cusatis-Miles-Woolridge 1993 and McConnell-Ovtchinnikov 2004)
- **Implementation**: `data/universe.py::SharadarSP500Universe`; `examples/sp500_survivorship.py::compute_survivorship_report` + `compute_cohort_nav_curve`; `data/adjustments.py::split_adjusted_prices_and_dividends` (the shared split adjustment) + `to_as_traded_dividends` (the dividend basis decode)
- **Figure**: [`docs/figures/survivorship_two_panel.png`](figures/survivorship_two_panel.png) (the PIT-cohort vs current-cohort equal-weight buy-and-hold NAV; the CAGR delta is the caption). The figure was deferred twice pending a survivorship total-return data-layer defect: Sharadar's ACTIONS `dividend value` is split-adjusted to the data-pull date, so left raw a reverse-split delisted name's reinvested terminal exploded to hundreds of x even though its split-adjusted price collapsed to ~0. ADR 0018 decodes the dividend to the as-traded basis at the data layer, the bankrupt names now read near-zero terminals, and the cohort curves render cleanly (the curve terminal equals the headline cohort mean terminal TR by construction). The figure carries the study's caveats: buy-and-hold is NOT the monthly-rebalanced 1.4-1.5pp Hsu-Hutchinson figure, the delta is dominated by current-cohort inclusion bias (today's members were selected for growing into the index), a median terminal TR is reported alongside the outlier-sensitive mean, and delisting cash earns zero T-bill.

### 6. Determinism and reproducibility

Every result is bit-reproducible: dependencies are pinned to exact patch,
multiprocessing uses spawn on both platforms with `POLARS_MAX_THREADS=1` per
worker, signal/policy code may not call module-level RNG or iterate sets, and the
figures regenerate from a committed artifact whose provenance (bundle, content
hash, git SHA) is stamped next to them.

- **Decision**: [`determinism.md`](methodology/determinism.md) (the twelve enumerated trust boundaries)
- **Implementation**: `engine/runner.py` (spawn workers); the AST lints in `tests/lint/`; `scripts/figures/` (the committed-artifact figure pipeline)

## Reproducing the figures

```
pip install -e ".[figures]"          # matplotlib (render-only; not a core dep)
python scripts/figures/regenerate.py # or: make figures
```

This renders every figure under `docs/figures/` from the committed artifact under
`scripts/figures/study_artifact/` in seconds, with no Sharadar bundle required.
To refresh the artifact from a fresh data pull (the slow ~15-20 min one-time
step): `python scripts/figures/build_study_artifact.py` (or `make figures-rebuild`).

## Honest conclusion (the kill-early thesis)

The milestone is structured to pass whether or not the strategy clears a Deflated
Sharpe of 0.95: a non-viable result is reported plainly rather than buried. The
cost band is a sensitivity surface, not a realized-cost forecast; the CPCV "fan"
is reported as degenerate for a deterministic factor; the survivorship figure
carries its buy-and-hold caveats. The point of the artifact is that every number
survives scrutiny, including the inconvenient ones.
